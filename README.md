# Bistro PAN — svetainės kodas

Atidarykite index.html naršyklėje. Visa svetainė yra HTML, CSS ir JavaScript.

## GitHub ir Vercel
Išskleiskite ZIP. Įkelkite index.html, style.css, motion.js ir assets aplanką į pagrindinį GitHub saugyklos lygį. Vercel pasirinkite Framework Preset: Other; Root Directory: saugyklos pagrindas; Build Command: tuščias; Output Directory: .
GitHub Pages: Settings → Pages → Deploy from a branch → main → /(root) → Save.

## Turinys
16 meniu patiekalų šešiose kategorijose, kontaktai, dienos pietūs, vegetariškos virtuvės ir Scrocchiarella picų aprašymas, 7 papildomų tikrų nuotraukų galerija. Veikia skambinimo, maršruto ir meniu nuorodos. Animacija prisitaiko prie reduced-motion nustatymo. Viršuje pateikta restorano Instagram paskyroje nurodyta Bolt Food nuoroda: https://food.bolt.eu/lt-LT/9-vilnius/p/21812-bistro-pan . Šaltinis: https://www.instagram.com/BISTROPAN_17/ .

## Nuotraukos
Nuotraukų pagrindas — tikra Bistro PAN galerija. Pirmame ekrane naudojama DI retušuota autentiško burokėlių karpačio nuotrauka (pan-salad-retouched.png); originalas pan-2807.jpg išsaugotas galerijoje. Retušui naudotas integruotas vaizdo redagavimas: išlaikyti patiekalą, lėkštę ir foną, švelniai koreguoti šviesą, baltos balansą ir aiškumą. Pagrindinė nuotrauka: https://www.dienospietus.lt/photos/2694/2799_medium.jpg. Picos nuotrauka: https://www.dienospietus.lt/photos/2694/2798_medium.jpg. Naudojama originali šaltinio raiška.
